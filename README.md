# Synapse — AI Research Workspace

Premium home page concept for the Acdyon frontend assessment.

## Product

Synapse turns a collection of research papers into an explorable map of concepts, methods, findings, and evidence.

## Core interaction

Click a concept in the research map to update the selected concept panel with its paper count, methods, description, and connected ideas.

## Stack

- Semantic HTML
- CSS
- Vanilla JavaScript
- No external runtime dependencies

The implementation intentionally keeps the assessment demo dependency-light. The research graph uses deterministic demo data rather than pretending to have a production AI backend.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static HTTP server.

## Deployment

The repository is intended to be deployed as a static site on Vercel.
